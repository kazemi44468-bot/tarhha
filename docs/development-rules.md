# قواعد توسعه

- هر طرح ابتدا در `tarhha` ثبت می‌شود.
- هر طرح صفحه مستقل و شناسه منوی پایدار دارد.
- دسته‌بندی و منوی مرکزی باید همگام باشند.
- صفحات طرح از `assets/css/sidebar.css` و `assets/js/sidebar.js` استفاده می‌کنند.
- برای طرح‌های بزرگ، ناوبری داخلی و بخش‌های اختصاصی مجاز است.
- پس از بلوغ، پروژه در مخزن مستقل ساخته می‌شود.
- لینک دوطرفه طرح و پروژه ثبت می‌شود.
- تغییرات مهم پروژه به سند طرح بازمی‌گردد.
- هیچ صفحه‌ای نباید منوی مرکزی موازی و ناسازگار بسازد.
- قبل از انتشار هر صفحه، مسیر فونت، منو، لینک‌ها، RTL و نمایش موبایل بررسی می‌شود.
