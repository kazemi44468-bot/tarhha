# طرح‌ها | Tarhha

این مخزن مرجع مادر برای ثبت، تدوین، دسته‌بندی و توسعه فکری طرح‌ها و ایده‌هاست.

## فلسفه
هر طرح مهم ابتدا در این مخزن از نظر مسئله، هدف، محتوا، دامنه، اجزا، معماری مفهومی، جزئیات، نقشه راه و وضعیت مکتوب می‌شود. پس از رسیدن به بلوغ لازم، برای اجرای آن یک مخزن پروژه مستقل ایجاد می‌کنیم.

**طرح = مرجع فکر، محتوا و تصمیم**  
**پروژه = مرجع کد، اجرا و انتشار**

این دو به هم لینک می‌شوند و تغییرات مهم پروژه به سند طرح بازمی‌گردد.

## ساختار
- index.html — خانه و فهرست طرح‌ها
- philosophy.html — فلسفه و روش کار
- categories.html — دسته‌بندی‌ها
- فایل‌های *-tarh.html — سند اختصاصی هر طرح
- assets/ — فونت‌ها، سبک و منوی مشترک

## قاعده توسعه
با اضافه‌شدن هر طرح جدید:
1. سند طرح در این مخزن ساخته می‌شود.
2. طرح در دسته مناسب قرار می‌گیرد.
3. لینک آن به منوی کناری اضافه می‌شود.
4. در صورت تصویب اجرا، مخزن پروژه مستقل ساخته می‌شود.
5. لینک دوطرفه طرح و پروژه ثبت می‌شود.
6. تصمیم‌ها و تغییرات مهم معماری به سند مادر برمی‌گردد.

هر صفحه جدید باید از منوی کناری مشترک استفاده کند تا کل مجموعه یکپارچه باقی بماند.
