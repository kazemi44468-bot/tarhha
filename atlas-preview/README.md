# پیش‌نمایش اطلس شهدا (Prototype)

نمونه عملیاتی مستقل برای سند طرح «اطلس شهدا» در ../pages/atlas-shohada-tarh.html.

## محتوا
- index.html — نقشه تعاملی Leaflet + لایه‌ها + جست‌وجو + فیلتر قطعیت + پرونده مکان
- data/places.geojson — داده نمونه مکانی (GeoJSON/WGS84)
- data/schema.json — Schema پیشنهادی موجودیت «مکان»

## اجرا
فایل index.html را باز کنید (نیازمند اینترنت برای کاشی‌های OpenStreetMap و Leaflet).

## گام‌های بعدی
1. جای‌گذاری داده واقعی بر پایه tools/*.json پروژه‌ها.
2. افزودن محدوده‌ها به‌صورت Polygon و سطوح عدم‌قطعیت.
3. اتصال دوطرفه با پروژه «تقویم شهدا» (مکان ↔ رویداد ↔ زمان).
4. پنل مشارکت، گردش بررسی و شاخص‌های کیفیت داده.
